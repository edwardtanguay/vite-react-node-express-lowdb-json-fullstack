# vite-react-node-express-lowdb-json-fullstack

This is a fullstack React/Node/Express/lowdb-json application that runs in one directory, useful for local development tools or internal applications.

## frontend

-   Vite React
-   TypeScript - types shared between frontend and backend
-   React Router 6.4 with createBrowserRouter
-   easy-peasy Redux (state management)
-   Zod (validation)
-   Tailwind, Sass
-   nodemon (hot reloading)
-   concurrently (runs backend/frontend with one command)
-   ESLint/Prettier
-   responsive

## backend API

-   Node/Express
-   TypeScript
-   lowdb with db.json (datasource)

## setup

-   `npm i`
-   `npm run dev` (starts both backend and frontend)
