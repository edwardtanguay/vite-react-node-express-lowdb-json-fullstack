# vite-react-node-express-fullstack

This is a fullstack React/Node/Express/lowdb-json application that runs in one directory, useful for local development tools or internal applications.

## frontend

-   Vite React
-   TypeScript
-   React Router 6.4 with createBrowserRouter
-   easy-peasy Redux (state management)
-   Zod (validation)
-   Tailwind, Sass
-   ESLint/Prettier
-   responsive

## backend API

-   Node/Express
-   TypeScript
-   lowdb/JSON (datasource)

## setup

-   `npm i`
-   `npm run dev` (starts both backend and frontend)
